# ifc-standard — skill de référence IFC

Accès normatif interrogeable aux schémas IFC2x3 TC1, IFC4 ADD2 TC1 et IFC4.3,
plus les Property Sets / Quantity Sets officiels.

    python3 scripts/ifc.py schemas
    python3 scripts/ifc.py entity IfcWall -s 4X3
    python3 scripts/ifc.py diff IfcWallTypeEnum

Voir SKILL.md pour l'usage complet, references/sources.md pour la provenance.
